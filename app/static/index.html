使用说明

计算前请先准备一个 .xlsx 表格，包含两个 sheet：【原始】 和 【量化】。 按下方说明整理好后，点击左侧「1. 上传文件」开始计算。
1
准备两个 sheet

新建一个 xlsx，里面放两个 sheet，分别命名为「原始」和「量化」。

2
【原始】表：直接粘贴成绩

把教务系统导出的原始成绩直接复制粘贴进来，不用修改格式。

注意不需要标题，直接从科目那一行开始，到最后一个人结束（带上平均成绩那一行也可以）。

3
【量化】表：整理扣分

整理成下图格式即可。其中「基础管理量化」一栏填写扣分，小空格位置是日期，形如 -2。

4
上传表格

表格整理好后，点击左侧「1. 上传文件」，选择该 xlsx 即可自动解析。

之后按步骤：选择参评科目 → 量化预览 → 开始计算 → 导出 Excel。

学年综测基于两个学期的综测结果文件进行计算。请先分别完成第一学期和第二学期的综测计算并导出结果文件，再在此处上传。
1
准备两份学期综测结果

先用「学期综测」模式分别计算第一学期和第二学期，导出两个 .xlsx 结果文件。

注意学年综测直接使用学期综测中已选好的参评科目和成绩，无需重新选择。

2
上传两份文件

点击「1. 上传学期综测」，分别上传第一学期和第二学期的综测结果文件。

程序会自动解析两份文件中的参评科目、成绩和量化数据，并自动识别挂科科目（成绩 < 60 分）。

注意未选的课程（如英语生→日语列空白）不会被误判为挂科。

3
标记补考及格

系统会列出所有挂科的学生和科目。请勾选补考通过的科目，勾选后该科绩点将记为 1（而非 0）。

挂科清单按学生分组，每人下方显示其挂科科目，点击即可勾选。

规则补考及格的科目绩点 = 1，未补考/补考未通过的科目绩点 = 0。

4
计算与导出

勾选完成后点击「开始计算」，程序会合并两学期的成绩和量化数据，计算：

· 学年综测平均学分绩点 = (第一学期总绩点 + 第二学期总绩点 + 量化绩点) / 两学期总学分（含量化）

· 学年学习平均学分绩点 = (第一学期科目绩点 + 第二学期科目绩点) / 两学期科目总学分

计算完成后点击「导出 Excel」即可下载学年综测结果表格，补考及格的绩点单元格会以黄色填充标记。

综测计算规则

综测成绩由学习成绩和量化成绩两部分按学分加权计算，最终得到平均学分绩点（含量化）作为综测排名依据。

一、量化成绩

量化成绩由两部分组成：

· 二课量化（第二课堂加分），原始分值直接填入

· 基础管理量化（按月扣分），每月填写扣分值（如 -2）

基础管理量化 = 100 − 各月扣分
量化成绩 = (二课量化 + 基础管理量化) ÷ 2
最终参评量化100分封顶

二、单科绩点

每门参评科目的绩点按以下公式计算：

单科绩点 = IF(成绩 < 60, 0, (成绩 − 50) ÷ 10 × 学分)
· 成绩 ≥ 60：绩点 = (成绩−50)/10 × 学分，如 85分3学分 → (85−50)/10×3 = 10.5
· 成绩 < 60：绩点 = 0（挂科）
· 补考及格：绩点 = 1

三、量化绩点

量化成绩作为一门 3 学分的"科目"参与绩点计算：

量化绩点 = IF(量化最终分 < 60, 0, (量化最终分 − 50) ÷ 10 × 3)
· 最终参评量化 ≥ 60：绩点 = (成绩−50)/10 × 3
· 最终参评量化 < 60：绩点 = 0（挂科）

四、平均学分绩点

将所有参评科目绩点求和，除以总学分，得到两个指标：

平均学分绩点(不含量化) = Σ单科绩点 ÷ 科目总学分
平均学分绩点(含量化) = Σ(单科绩点 + 量化绩点) ÷ (科目总学分 + 3)

含量化的平均学分绩点即为综测成绩，用于综测排名。

五、排名与百分比

· 综测排名：按平均学分绩点(含量化)降序排名

· 学习排名：按平均学分绩点(不含量化)降序排名

· 量化排名：按量化最终分降序排名

· 百分比 = 排名 ÷ 总人数

六、学年综测

学年综测合并两个学期的数据：

· 学年综测平均学分绩点 = (S1总绩点 + S2总绩点 + 两学期量化绩点) ÷ (S1总学分 + S2总学分 + 6)

· 学年学习平均学分绩点 = (S1科目绩点 + S2科目绩点) ÷ (S1科目总学分 + S2科目总学分)

· 补考及格的科目绩点记为 1，未补考/未通过记为 0
