# 洛阳师范学院综测计算程序

## 欢迎添砖加瓦

本项目完全开源，欢迎所有人参与贡献！无论是修复 Bug、优化代码、改进计算逻辑，还是完善文档，都非常欢迎。

### 贡献方式

1. **Fork** 本仓库到自己的 GitHub 账号
2. 在 Fork 的仓库中创建新分支进行修改
3. 提交 **Pull Request**，描述清楚修改内容
4. 等待审核合并

如果只是小修小补（改错别字、调样式等），也可以直接在 GitHub 网页上点编辑按钮，GitHub 会自动帮你 Fork + 发起 PR，一步到位。

> 如果你有好的想法或发现 Bug，也欢迎在 [Issues](https://github.com/Voider-Li/LYNU-ZongCe-Calculator/issues) 中提出讨论。
